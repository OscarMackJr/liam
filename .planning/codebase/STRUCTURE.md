# Codebase Structure

**Analysis Date:** 2026-10-21

## Directory Layout

```
liam/
├── AGENTS.md              # Implementation constraints (binding)
├── Cargo.toml / Cargo.lock
├── README.md              # Status, assumptions, contract notes
├── RESULTS.md             # Measured test scope
├── liam.toml              # Runtime config (policy + locations, no secrets)
├── .cargo/config.toml     # Vendored/offline sources, static CRT
├── .github/workflows/ci.yml
├── src/                   # Library + binary
│   ├── main.rs            # CLI entry
│   ├── lib.rs             # Module exports + startup unit tests
│   ├── config.rs  receipt.rs  expectancy.rs  task.rs  evidence.rs
│   ├── stubs.rs           # feature "stubs" only
│   └── clients/           # mod.rs (proxy client), hometown.rs, olive.rs
├── tests/                 # Integration tests (process + proxy contracts)
├── contracts/             # Wire/record schemas, catalog, receipt field notes
│   └── vendored/          # vocabulary.yaml + VENDORED.md (SHA-pinned copy)
├── profiles/liam.nono.toml  # Draft nono profile for owner review
├── scripts/               # PowerShell launchers/helpers
├── stubs/records/         # Stub record docs
├── runs/                  # Local run output placeholder (.gitkeep)
├── specs/                 # Design/test specs v0.1-v0.4.1, decisions, amendments
│   ├── _agent_inputs/     # Handoff inputs from other components (nono, Popeye, Hometown, Olive)
│   └── nextSteps/         # Cross-component prompts
├── vendor/                # Vendored crates (~8.6k files, committed; do not edit)
└── target/                # Build output (ignored)
```

## Directory Purposes

**`src/`:**
- Purpose: all Rust code; one module per concern
- Key files: `src/main.rs`, `src/receipt.rs`, `src/task.rs`, `src/clients/mod.rs`

**`tests/`:**
- Purpose: black-box tests using the `stubs` feature; `tests/process_contract.rs` runs the binary against stubs and capture proxy, `tests/proxy_contract.rs` checks proxy transport (one `#[ignore]` test touches HKCU Internet Settings)

**`contracts/`:**
- Purpose: authoritative machine-readable contracts: `agent-record.schema.json`, `hometown-answer.S-HT-1.json`, `olive-proposal.S-OL-1.json`, `catalog-0.4.json`, `receipt-fields.md`
- A contract mismatch requires updating these and `README.md`, then stopping.

**`specs/`:**
- Purpose: versioned specs; latest are `specs/LIAM_DESIGN_SPEC_v0.4.1.md`, `specs/LIAM_TEST_SPEC_v0.4.1.md`, `specs/LIAM_AMENDMENT_v0.4.1_proxy-transport.md`.

**`vendor/`:**
- Purpose: offline crate sources; generated by `cargo vendor`; committed. Checksums must be preserved (`.gitattributes`).

## Key File Locations

**Entry Points:**
- `src/main.rs`: binary `liam`
- `scripts/launch-under-nono.ps1`: launch under nono

**Configuration:**
- `liam.toml`: agent, nono, hometown, olive, vocabulary, evidence settings
- `profiles/liam.nono.toml`: nono profile draft
- `.cargo/config.toml`: offline build

**Core Logic:**
- `src/receipt.rs` (startup validation), `src/task.rs` (answer/proposal flow), `src/clients/` (HTTP), `src/evidence.rs` (records)

**Testing:**
- Inline `#[cfg(test)]` modules in `src/*.rs`; integration in `tests/*.rs`

## Naming Conventions

**Files:**
- snake_case Rust modules: `receipt.rs`, `process_contract.rs`
- Contracts: `<subject>.<contract-id>.json` (e.g. `hometown-answer.S-HT-1.json`); specs `LIAM_<KIND>_v<ver>.md`

**Directories:**
- lowercase, short; `clients/` groups per-service clients.

**Code:**
- Types PascalCase, functions snake_case; error reason strings `area:detail` (`receipt:pid`, `agent_record:key_expiry`, `hometown:unavailable`).

## Where to Add New Code

**New downstream service client:**
- `src/clients/<service>.rs` with a trait + `Http*Client::new(client, base_url, timeout)`; declare in `src/clients/mod.rs`; reuse the `ProxyClient` client; add stub in `src/stubs.rs`.

**New startup check:**
- `src/receipt.rs` (`validate_startup`) or `src/config.rs`; reason code `area:detail`; wire exit code in `src/main.rs` (10 nono, 11 config/env).

**New receipt layer expectation:**
- `src/expectancy.rs` (`accepts`, `ALL_LAYER_IDS`), plus `contracts/receipt-fields.md`.

**New exit code/outcome:**
- `src/main.rs` match on `TaskError`; document in README.

**Tests:**
- Unit: inline module in same file. Integration: `tests/*.rs` using `liam::stubs` (needs `--features stubs`).

**Config keys:**
- Add to structs in `src/config.rs` and `liam.toml`; never put credentials in either.

## Special Directories

**`vendor/`:** generated: yes; committed: yes.
**`target/`:** generated: yes; committed: no.
**`runs/`:** runtime output placeholder; real evidence goes to `%LOCALAPPDATA%\Fiskroad\liam\runs`.
**`specs/_agent_inputs/`:** copied inputs from other components; read-only references.
**`.planning/codebase/`:** generated codebase maps.
