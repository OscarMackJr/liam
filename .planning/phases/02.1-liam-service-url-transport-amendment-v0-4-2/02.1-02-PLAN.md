<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment -> Liam | NONO_SERVICE_*_URL values are untrusted until validated |
| agent record -> Liam | proxy_port from nono-written record is the trusted reference |
| Liam -> loopback | only 127.0.0.1:<proxy_port> may ever be connected to |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-021-04 | Spoofing | service URL redirect to other host | mitigate | exact-form manual parse (IPv4 literal 127.0.0.1, http only, no userinfo/query/fragment), round-trip port check; obfuscated IP forms rejected by unit tests |
| T-021-05 | Tampering | port/route mismatch to another local listener | mitigate | check_service_port against record proxy_port; exact route equality per variable |
| T-021-06 | Information disclosure | URL/port in stderr | mitigate | reasons are fixed strings from config.rs; no value interpolated |
| T-021-07 | Elevation | ambient proxy / WinINET routing | mitigate | no_proxy() kept, Proxy::all removed, forward-proxy env vars never read, deny-all resolver kept |
| T-021-08 | Denial | request before prerequisites | mitigate | all checks precede Evidence::new and any client call; exit 11 |
</threat_model>
