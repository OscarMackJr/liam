# Liam — Windows Desktop Agent: Test Specification v0.4

Version: 0.4
Status: **Ratified 2026-10-19, POC scope** — companion to `LIAM_DESIGN_SPEC_v0.4.md`. Section references (§) point there unless stated.
Audience: the implementing LLM agent, reviewers of the POC evidence.

**Changes in 0.4 (receipt contract):** fixtures are now pairs of a fork-shaped `EnforcementReceipt` (schema 2) and an `AgentSessionRecord` (`NONO_v0.4.3`); TC-START rewritten as TC-START-01..16 against design §4.2–§4.4; key and session references point at the agent record.

**Changes in 0.3 (gap G5):** the gateway stub is removed; hometown's answer endpoint absorbs the model-path behaviours. TC-CTX replaced by TC-ANS. TC-KEY, TC-META, TC-FAIL and TC-ACT rewritten against hometown and olive stubs. New TC-START-13 (injection set), TC-NET-04 (gateway blocked), TC-E2E-07 (gateway attempt detected). TC-E2E-01 and -05 revised for hometown-made model calls.

**Changes in 0.2:** agent-key receipt fixtures; TC-START-10..12; TC-E2E-05/06; TC-LVOC rename.

Principle: **a test passes when Liam refuses, fails closed, or produces the required record.** A run that proceeds with a check missing is a failure even if nothing bad happened. Results are measurements with their limits, never claims.

## 2. Fixtures

### 2.1 Stubs (`stubs/`, feature `stubs`)

| Stub | Behaviours |
|---|---|
| `hometown-stub` (S-HT-1) | 200 answer without proposal; 200 with one valid proposal; 200 with an out-of-catalog proposal; 200 with schema-invalid parameters; 200 with two proposals (non-conforming); 200 with `context_complete=false`; 200 whose answer and justification contain command text and extra JSON keys; 401 no key; 401 key inactive; 403 purpose refused; 409; 429; 500; 100 s delay |
| `olive-stub` (S-OL-1) | 202 `awaiting_approval`; 200 `refused_policy` with reason; 400 schema error; 500; catalog endpoint serving `catalog-0.4.json` |
| `gateway-trap` | A listener on a host standing in for the gateway FQDN, used only to prove Liam never reaches it (TC-NET-04). It records any hit. |

Every stub writes each request (method, path, header names with an `Authorization` presence flag, body) to a capture file.

**Injection simulation.** In `ci-elevated` runs there is no nono-proxy. The capturing test proxy (TC-NET-01) adds a sentinel credential header on hometown and olive requests only, standing in for nono's injection, so stubs can assert the header arrived from the proxy and not from Liam.

### 2.2 Record fixtures (`stubs/records/`)

Each fixture is a pair, `receipt.json` (fork `EnforcementReceipt`, schema 2) and `agent.json` (`AgentSessionRecord`, schema 1), generated by `make-stub-records.ps1` at test time so `pid`, `written_at_unix`, `key_expires_at_unix` and `proxy_port` match the run. Fixtures are produced from a base pair by applying one named mutation. The base pair (`valid`) has:

- receipt: `schema_version=2`, `entry_path=DirectCli`, `token_arm` = the stub value configured in `nono.expected_token_arm`, `outcome=Ran`, fourteen census rows each at the strictest accepted status in design §4.3, `pid` = the Liam process under test;
- agent record: `agent_id=liam`, `purpose=servicing`, a lowercase UUID `key_id`, expiry +1 h, `injected_on=[hometown, olive]`, `direct_gateway=false`, `profile_version` = config minimum, `proxy_port` = test proxy port, `written_at_unix` = now.

| Mutation | Target | Change |
|---|---|---|
| `receipt-missing` / `agent-missing` | file | File absent |
| `receipt-schema-1` | receipt | `schema_version=1`, thirteen rows (pre-v0.4.3 shape) |
| `refused` | receipt | `outcome=Refused` |
| `wrong-entry` | receipt | `entry_path=Broker` |
| `low-il-arm` / `broker-arm` | receipt | `token_arm=LowIlPrimary` / `BrokerLaunchNoPty` |
| `unconfigured-arm` | receipt | `token_arm` differs from `expected_token_arm` |
| `pid-mismatch` | receipt | `pid` of another process |
| `census-13` / `census-dup` | receipt | One row missing / one row duplicated |
| `appcontainer-unconfirmed` | receipt | `AppContainerProfile=Unconfirmed` |
| `wfp-established` | receipt | `WfpEgressFilters=EstablishedNotIndependentlyObservable` (requires `Confirmed`) |
| `agentkey-unconfirmed` | receipt | `AgentKeyInjection=Unconfirmed` |
| `minifilter-unconfirmed` | receipt | `MinifilterAbsence=Unconfirmed` (requires `NotApplicable`) |
| `out-of-scope-variety` | receipt | The five "any status" rows set to mixed values (must still pass) |
| `session-mismatch` | agent | `session_id` differs from the receipt's |
| `agent-other` | agent | `agent_id` not `liam` (fixture uses an unknown enum string, expecting a parse failure) |
| `purpose-mismatch` | agent | `purpose=analytics` with `--purpose servicing` |
| `keyid-upper` / `keyid-numeric` | agent | Uppercase UUID / JSON number |
| `key-expiring` | agent | Expiry +60 s (below the 180 s floor) |
| `inject-gateway` / `inject-missing-olive` | agent | `injected_on` includes `gateway` / lacks `olive` |
| `direct-gateway-true` | agent | `direct_gateway=true` |
| `old-profile` | agent | `profile_version` below minimum |
| `port-mismatch` | agent | `proxy_port` differs from `HTTPS_PROXY` |
| `stale` / `future` | agent | `written_at_unix` 10 min old / 60 s ahead |
| `dsse-valid` / `dsse-bad` | both | Envelope over both files valid / invalid against the test key |

Writability is set by the harness (TC-START-06).

### 2.3 Real nono

The nono fork at a pinned commit with `profiles/liam.nono.toml`. Every result records the fork commit, receipt version and Windows build (`ver` plus UBR).

## 5. Exit Criteria for the POC

1. Every `ci-elevated` TC green on the pinned toolchain.
2. Every `dev-standard-user` TC `verified`, 3 of 3.
3. TC-E2E-01, -03, -04, -05, -06 and -07 `verified` on at least one managed workstation; TC-E2E-02 has carried one detection end to end.
4. S-HT-1 and S-OL-1 confirmed or replaced by owner-approved contracts.
5. `NONO_v0.4.2` / `POPEYE_v0.4.2` implemented; `NONO_v0.4.3` / `POPEYE_v0.4.3` ratified and implemented; O7 (token arm and expectancy review) closed; ATE gap G6 resolved or recorded as blocking.
6. The vendored vocabulary hashes to the spec value `60a44f00…e8e7` (any recorded placeholder deviation removed).
7. Results published in the `liam` repository and summarised for the Fiskroad coordination repository.

Not required and must not be claimed: fleet distribution, log shipping, execution of actions, CrowdStrike coexistence beyond the nono fork's own soak.
