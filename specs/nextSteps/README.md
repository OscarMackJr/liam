# Fiskroad Component Next Steps

This directory is the execution packet for the work after Liam's local stub
matrix. Its reader is a component owner or implementation agent who must make
their component ready for the first real Liam session.

Read `CROSS_COMPONENT_EXECUTION_SPEC.md` first. Then use the prompt for the
component being assigned:

1. `PROMPT_NONO.md`
2. `PROMPT_POPEYE.md`
3. `PROMPT_HOMETOWN.md`
4. `PROMPT_OLIVE.md`

The prompts are work orders, not permission to change a ratified boundary.
When a requested wire shape, security property, or ownership decision conflicts
with a governing specification, record the difference and stop for joint
review.

Liam's local results are documented in the repository's `RESULTS.md`. They
are evidence for the stub harness only; no prompt may turn them into a claim
about a live service, a real nono session, or a managed endpoint.
